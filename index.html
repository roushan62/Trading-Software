How accurate is the data?

  • Binance live: direct public Rest API (`api.binance.com`) — real exchange OHLCV and 24h ticker. This is the most accurate option in the browser.
  • CSV: you provide your own file, so data is exactly what you upload.
  • Demo: fully offline synthetic data used for testing the engine.
  • Stocks (AAPL/RELIANCE.NS): popular stock symbols are not available via Binance. Select CSV file or a public proxy source for those. The app never guesses stock prices.

Indicator & signal rules

  • EMA 20/50/200 trend gate, session/rolling VWAP, Wilder RSI(14), Wilder ATR(14), volume z-score, fractal swing market-structure, auto S/R.
  • Every signal includes entry, stop-loss, target, R:R, confidence and plain-English reasons. A signal without a stop is never emitted.
  • Backtest uses closed bars only, fills on next bar open with slippage, assumes stop hits first if both levels are touched in one bar.
